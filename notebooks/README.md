# Notebooks

This folder contains notebooks used for experiments, analysis, and the extension pipeline.

## Important note about working directory

Many notebooks assume they are executed with the repo root `aml-procedural-mistake-detection/` as the current working directory.
If you open a notebook from this folder and paths fail, either:

- start Jupyter from the repo root (recommended), or
- add `os.chdir('..')` as the first cell.
